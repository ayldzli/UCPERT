# University Course Planner and Elective Recommendation Tool (UCPERT)
This project is a web-based application developed to simplify university students' course registration processes, automate graduation audits, and intelligently recommend elective courses tailored to their career goals.

## Feature Goals
- **Smart Schedule Builder:** Plan conflict-free course schedules.
- **Prerequisite Tracking:** Automatic validation of mandatory prerequisite courses.
- **Elective Recommendation Engine:** Suggests the most suitable elective courses based on student interests and career targets.
- **Graduation Audit:** Visual tracking of completed and remaining courses.

## Technology Goals
- **Frontend:** Next.js / React, Tailwind CSS
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL

## Project Structure
- `/frontend` - User interface code
- `/backend` - API and business logic
- `/docs` - Project plans and reports (including SDP)
